# Simulador de videos cortos · investigación

Sitio estático de un estudio académico sobre consumo de videos cortos.

- `index.html`: vista para participantes (teléfono).
- `inyector.html`: consola del equipo investigador; requiere cuenta autorizada.

Los datos se guardan en un proyecto Supabase con acceso restringido. Este repositorio no contiene claves privadas:
la clave incluida en los HTML es la clave **publicable** de Supabase, pública por diseño.
No es una aplicación oficial de ninguna red social.
